# astock-paper-trading

A 股量化**模拟盘**交易引擎。多策略日内轮动 + 完整撮合/风控/审计闭环，用于策略研究、风控规则验证与参数进化，不涉及真实资金。

> 说明：本仓库仅包含**架构与源码**，不含任何部署配置、运维脚本、服务器信息与运行时数据。

## 核心设计

- **模拟撮合带风控门禁**：所有买单/卖单先过风险决策层（`paper_risk_decisions`），拒单原因结构化留痕；撮合对 T+1、停牌、涨跌停、最小交易单位做硬校验。
- **分层卖出状态机**：下行守卫（预警→连续两次确认→按级别减仓）、硬止损（首段减仓→跌破确认全清）、止盈（移动止损 + 阶梯分档）；退出原因以结构化标记写入订单台账，便于状态恢复与回测归因。
- **共享资金池**：多策略共享一个资金池，席位（最大持仓数）与预算（单票金额）由中央预算分配，含公平性保护与地板，防止策略间互相挤占。
- **并发正确性**：cron 触发的扫描进程通过「全局租约 + fencing token + 心跳续期 + 完成 CAS」保证同一时刻只有一个 writer，进程被杀/挂死可自动回收且不产生重复订单。
- **全链路可审计**：每个决策、订单、成交、NAV、扫描轮次都有留痕（审计事件/风险决策/运行台账），可逐轮回放定位问题。

## 目录结构

```
backend/
  paper_trading.py        模拟盘撮合/风控/审计主引擎
  paper_runner.py         调度入口（slot: auction/open/intraday/close…）
  data_fetcher.py         行情/快照/公告多源数据层
  entry_timing.py         入场时机状态机
  decision_engine.py      车道/因子判定
  adaptive_*.py           自进化观测与调参（影子权重，不改实盘）
  news_learning.py        新闻舆情学习
  api_*.py                HTTP API（看板/操作端点）
frontend/                 Web 管理看板（策略状态/持仓/风控/审计回放）
Dockerfile                容器镜像定义（应用镜像，不含编排细节）
docker-compose.server.yml 服务编排骨架（占位，不含真实主机信息）
```
