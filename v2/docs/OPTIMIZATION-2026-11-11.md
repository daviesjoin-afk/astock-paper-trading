## 已完成

业务依赖保持 **HTTP → store → domain**：估值归 `domain/valuation.rs`，持久化和事务归 `store/mod.rs`，网页展示读模型。一个 Cargo package，没有新服务或项目依赖。

- 策略金额盈亏扣除累计净转入，两槽金额盈亏之和仍等于账户盈亏。
- 槽位收益按日末资金流中性时间加权计算，回撤来自同一收益曲线；最大回撤峰谷锁定同一事件，初始本金作为首日亏损的峰值。
- 缺持仓报价明确返回 `missing_close_price`，不吞成空值；无行情的初始账户保留暂无估值契约。
- 停牌行保留官方参考昨收，只能给已有持仓估值，不能交易、评分或进入市场状态。旧 `none/tdx` 表新增 `tradable` 时一次性分类，列创建和分类原子提交；已有显式标志和前复权行不被重写。
- `examples/regime_ab.rs` 复用原 `Store::advance`，输入只读固定快照，账本只在内存；每天只使用截至当日的窗口，不用未来区间筛选股票。
- 两算法已接入 [策略库](STRATEGY-LIBRARY.md) 的统一接口及显式注册表，120 组真实输入的分数/原因与旧实现逐项一致；固定两槽、下单和风控政策保持。
- `research/verify_ab.py` 从成交独立重建整数账本及精确收益；`research/backfill_halted.py` 从官方日包补旧研究副本并留来源 manifest，两者与行为测试一起纳入代码。

## 离线复核入口

从仓库根执行，Windows 无 MSVC 时给 cargo 加 `+1.99.1-x86_64-pc-windows-gnu`：

```bash
cargo run --release --locked --manifest-path v2/Cargo.toml --example regime_ab -- \
  --db work/real-history/db/research-market-halt-boundary.sqlite3 \
  --from 2023-07-05 --through 2026-11-11 --initial-cash-cents 10000000 \
  > work/real-history/ab-full-reproduced.json \
  2> work/real-history/ab-full-reproduced.log
```

确认回放退出 0 后再独立核算：

```bash
python -B v2/research/verify_ab.py work/real-history/ab-full-reproduced.json \
  --db work/real-history/db/research-market-halt-boundary.sqlite3 \
  --out work/real-history/ab-full-reproduced.verification.json
```

`10000000` 分为 10 万元；100bps 为 1%。报告含逐日曲线、成交、费用、持仓、调拨及输入窗口。错误只写 stderr，回放失败退出 2；重定向创建文件不代表成功。

`.data/`、`work/` 和数据库未进 Git。新电脑获取原研究副本或按接续说明重建；随代码提供精确核算摘要和 933 日包指纹，不能把 GitHub 拉取完成当成数据已就绪。

## 解释边界

旧策略分项收益把资金调配算成收益，旧 A/B 金额还存在分/元混淆；这些数字已作废重算，不能拿来证明自动分配有效。

当前仍是同日收盘信号/成交模型，没有完整公司行为权益、逐日历史费率和盘中成交条件；不复权输入避免历史被前复权改写，却不自动补齐总回报。核算器验证导出账本，不独立重新选股。现金流中性收益消除了调拨直接产生的假收益，不保证两组的资金规模和持仓路径相同。
