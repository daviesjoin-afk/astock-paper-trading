# ADR 007：账户净值序列与回撤

状态：已实现（原提案已落地，证据见验收对照表）。本轮落地**纯域与只读投影**：给定显式交易日列表与一个审核价格集合，逐日重放成交并盯市，产出权益序列与最大回撤；缺覆盖即整条序列不可用，绝不插值。

## 问题

ADR 006 定义了单时点估值。MVP 2（按绩效调整资金）与进化评估需要**时间序列**：账户在多个交易日的权益、以及从峰值到谷底的回撤。若用近似值填补缺失日，任何绩效结论都不可信。

## 决定

### 1. 输入

- 账户（初始本金、槽位成交）；
- 一个 `reviewed` 价格集合（ADR 006），必须覆盖**全部**请求日与**全部**持仓标的；
- 调用方显式给出的交易日列表：`YYYY-MM-DD`，严格递增、不得重复。

### 2. 逐日重放（确定性）

对每个请求日 `d`：

1. 按 `trade_day` 升序把 `trade_day ≤ d` 的成交应用到同一本账（现金与持仓只前进，不回滚）；
2. 用价格集合在 `d` 的收盘价计算市值；
3. 记录 `{day, cash_cents, market_value_cents, equity_cents}`，其中
   `equity = cash + market_value`（现金为账户级：准备金 + 两槽现金，因为成交重放从初始本金出发）。

任何一天缺价、数据包不匹配或日期越界 → 整条序列拒绝（`valuation_missing_symbol` / `valuation_pack_mismatch` / `valuation_day_outside_price_set`），不输出部分序列。

### 3. 回撤

- 峰值 = 截至当日的历史最高权益；
- 回撤 = 峰值 − 当日权益；
- 输出最大回撤（整数分）与其发生日；
- **不**输出百分比、年化、夏普、索提诺或胜率：这些需要明确的年化约定与样本量声明，属于后续 ADR。

### 4. 盈亏

- 仅 `reviewed` 集合：`profit_cents = 最后一日权益 − 初始本金`；
- `synthetic` 集合：序列可用于测试，但 `profit_cents = null`，且不得进入用户界面。

### 5. 只读与确定性

- 序列由账户成交 + 价格集合派生，不写任何账本，不持久化；
- 同一账户、同一日列表、同一集合 → 相同序列与相同 `digest`（canonical 摘要，去掉 `digest` 字段自身）。

## 验收（本轮）

1. 两天序列：逐日现金、市值、权益正确，回撤等于价差 × 数量；
2. 请求日超出集合覆盖 → 整条序列不可用（不裁剪）；
3. 缺某个持仓标的价格 → 整条拒绝；
4. `synthetic` 集合不被用户路径选中；即使直接调用也 `profit_cents = null`；
5. 内置价格集合目录为空时，HTTP 返回 `unavailable`。

## 接口

`GET /v2/paper-accounts/{id}/equity-series?days=2026-10-30,2026-11-02`

- 覆盖齐全：`{status:"valued", trust, price_set_id, points[], max_drawdown_cents, max_drawdown_day, profit_cents, digest}`；
- 无可用集合：`{status:"unavailable", reason:"no_reviewed_price_set", days:n}`；
- 交易日列表为空 → 422 `empty_equity_series`。

## 未决问题

- 交易日列表由谁给出：调用方显式传入（当前）还是从交易日历展开？倾向下一轮增加“按 from/to 展开日历”，但必须引用固定日历版本。
- 停牌日如何处理：跳过、沿用最后价、还是拒绝？当前规则是“缺价即拒绝”，最保守。
- 分红送转/复权：价格集合必须声明复权口径，否则跨除权日的序列不可比。
- 是否需要持久化每日序列：当前按需重算，不新增写入者。
