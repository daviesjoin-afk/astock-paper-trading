# ADR 001：独立实验与输入版本

状态：接受。基线：#353 合并提交 101fcf0054845092aaa994c7296a47a838350f0c，11 项检查通过。

## 问题与决定

V2 是独立实验系统，不是 V1 移植。现有 cycle_id 只用于去重，资金重建、决策时间顺序、查询与回放均扫描全库；不同 cycle 会共享资金及持仓。

直接将 cycle_id 定义为 Experiment 唯一身份，不增设第二套 account/experiment_id。必须先显式创建实验；创建后初始资金、StrategyArtifact、MarketDataPack、ExecutionPolicy 不可替换。信号契约升为 3，拒绝旧契约；数据库升为 schema 6，因为新增实验归属约束，旧文件只读拒绝，不推断旧账本归属、不自动迁移。初始资金不再是 Store 或进程级参数。

## 事实所有权

| 对象 | 所有权及边界 |
| --- | --- |
| Experiment | Store 持久化 cycle_id、初始分币资金、策略版本、数据包引用、执行规则版本及 active/completed 状态。Domain contract 定义契约；只允许 active → completed，完成后仅可读及幂等重试。 |
| StrategyArtifact | 不可变策略版本及研究输入身份，由 Store 首次登记并拒绝同版本异内容。Python 只产出研究身份和信号，不决定数量、成交或账本。身份不是策略有效性认证。 |
| MarketDataPack | 按明确版本选择已审核离线快照；包含来源、覆盖时间、内容摘要、信任等级及证据身份约定。行情证据只追加、同身份不得替换；每次决策固定实际证据（含缺失），完成实验的输入为这些固定事实。 |
| ExecutionPolicy | Rust 执行算法版本；明确分派支持版本，未知版本失败。与数据包及 SQLite schema 分开。旧成交只按记录版本回放，历史资产查询只投影已存成交。 |
| Ledger | 每个 cycle 的决策、成交、现金、持仓、T+1 与时间顺序。Store 唯一写入者；query 只读。成交通过 run 的外键继承实验归属，不再复制另一份资金权威。 |

依赖保持 HTTP → Store → Domain，单 Cargo、单服务、单 SQLite 写入者。复用 contract、portfolio、execution、store/query，不新建空模块或基础框架。

## 版本扩展的最小边界

目前 open/load_market_context 将数据库 JSON 与唯一编译时 JSON 作严格相等比较。这防止快照被替换，但把“当前程序的样本集合”变成“所有旧实验唯一合法输入”。新增证券本身并不改变关系表结构，不能因此再要求新数据库。

数据包登记应是按 pack_id 解析固定内容，而非解析 latest：保留旧包，增加新包；同 ID 改内容失败。SQLite schema 仅在结构/约束变化时升级。规则实现保留明确的版本分派；不支持旧规则时明确拒绝，不静默回退。实验引用固定 pack_id 和 policy_version。新包验证必须覆盖身份、日历、证据来源与内容一致性，不能通过自报信任等级升级。

本次先实现实验归属与固定版本引用，仅开放一个审核过的 offline_fixture 包。现有编译快照校验仍作为该包的完整性检查，不宣称已支持任意包导入。后续新增包采用显式登记表/受审核包清单和按版本加载；可增加数据记录和支持版本，不改变实验/成交表结构。通用插件、动态规则加载、复杂迁移均不在本轮。

共享离线证据是多个反事实模拟实验的共同输入，不是多个实验竞争一份真实市场流动性。容量仍在每个实验的单次决策中校验；不承诺市场级成交真实性。

## 验收

先用现有接口证明 A 买入后 B 被 position_already_open 错误拒绝，再加入显式创建与隔离。覆盖独立初始资金、同信号身份跨实验、实验内重试、T+1、资金限制、历史视图、时间顺序、事务失败、重启、证据冲突、逐实验完整回放及完成后不可追加。固定 Python → Rust → SQLite → HTTP 演示复用同信号，验证不共享现金、持仓或决策数。

不修改 V1，不部署，后续 PR 保持 Draft。没有新增库依赖、微服务、调度、自进化或真实交易接口。

## 当前数据包的可检查内容

cn-offline-fixture-pack-1：信任等级 offline_fixture。交易日历来自 data/calendar-2026-v1.json 的两所公告及原文 URL，覆盖 2026 年；身份/数量规则来源、原文位置及文件 SHA256 在 data/instruments-offline-v1.json，适用覆盖为 2026-10-27 至 2026-11-05。时段规则为 data/session-policy-v1.json。内容摘要：一个支持的普通主板 A 股样本 600000.SH，STAR/ETF 为明确拒绝样本，不代表全市场证券库。

fixtures/quote.json 和测试生成的价格/容量都是人工合成回归输入。证据命名空间为 offline-fixture + quote_id，Store 记录来源、声明时点、首次接收时点和不可覆盖内容；每个实验的实际数据集由其决策固定的证据引用及完整快照组成。研究输入 ID 是不可变身份声明，不是研究代码内容的签名或有效性认证；更换研究输入必须使用新的策略版本。
