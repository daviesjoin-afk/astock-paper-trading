# 可成交性：涨跌停封板（2026-11-12）

改动基于已推送的 `e955e08`。只增加“这一侧能不能成交”的判断，不改评分、阈值、手续费、整手、T+1、单笔额度或调仓逻辑。

## 为什么需要

有收盘价不等于能成交。跌停封死时盘口没有买盘，收盘价只是估值；把它当成卖出价，等于把“卖不掉”记成“在最低点卖掉”。实测全期 4,395,884 行不复权行情里，触及涨停 0.879%、跌停 0.282%，其中 **806 行是全天同一价位的跌停**——这类日子想卖也卖不掉。

## 判定规则

```
单边封板 = 开=高=低=收（全天一个价位）
        且 该价 触及 板块涨跌停价
跌停封板 → 不能卖，能买
涨停封板 → 不能买，能卖
```

- 板块幅度不是一刀切 10%：北交所 30%，创业板/科创板 20%，主板 10%。
- 用交易所给的**参考昨收**（`prev_close_cents`）判断，而不是上一条不复权收盘。除权日 10 元跳 5 元是拆股，用旧收盘会误判成跌停并把所有卖出都锁一天。
- 只是“收在涨跌停价”不够：盘中若在别的价位成交过（高≠低），当天依然可以正常成交。
- 缺开高低或参考昨收时**不推断封板**，保持可成交——宁可保守地少拦，也不凭空造限制。

实现在 `v2/src/domain/session.rs`，由 `PriceSet::from_bars` 在构建价格集合时逐行计算，结果落在 `PriceEntry.can_buy/can_sell` 与索引的 `Quote` 上；结算在生成订单后按方向过滤。价格集合的 schema 没变（新字段有默认值 `true`），旧的显式价格集合仍然有效。

## 覆盖的边界

| 情况 | 结果 |
| --- | --- |
| 全天一个价位收在跌停 | 不能卖 |
| 全天一个价位收在涨停 | 不能买 |
| 盘中换手后收在跌停价 | 两侧都能成交 |
| 停牌（`tradable=false`） | 本来就不能成交，不额外推断封板 |
| 创业板 15% 下跌 | 未触 20% 限制，正常成交 |
| 除权缺口（参考昨收已调整） | 不判为封板 |

对应回归：`session_tests.rs` 六项（含板块幅度、除权参考价、缺字段不推断），以及 store 层两项——跌停封板下持仓必须保留、止损在两种时点下都要触发。

## 仍未建模

- **盘中止损/跳空**：按收盘价成交，不模拟跳空穿过止损位的真实成交价。
- **流动性**：不看成交量与持仓量的比例，小票大额单仍按收盘价全额成交。
- **涨停买入排队**：封板排除买入，但“封板被打开后成交概率”没有建模。
- **ST 股 5% 限制**：没有 ST 标记数据，一律按所在板块幅度处理，可能低估 ST 股封板频率。
- **新股上市首日无涨跌幅限制**：没有上市日信息，会按板块幅度判断，可能误判为封板。

这些限制意味着结果仍偏乐观，不能当作可执行收益。

## 全期影响（813 个结算日，本金 ¥100,000）

同输入、同阈值，仅加上封板判断：

| 口径 | 期末资产 | 精确收益 | 最大回撤 | 成交 |
| --- | ---: | ---: | ---: | ---: |
| 同日 / 关闭 | ¥79,018.73 | −20.981270% | 32.0198% | 1122 |
| 次日 / 关闭·未加封板 | ¥71,798.15 | −28.201850% | 36.2512% | 1122 |
| **次日 / 关闭·加封板** | **¥70,707.18** | **−29.292820%** | **36.4416%** | **1102** |
| 同日 / 开启 | ¥119,318.05 | +19.318050% | 13.6873% | 496 |
| 次日 / 开启·未加封板 | ¥110,552.72 | +10.552720% | 13.6784% | 510 |
| **次日 / 开启·加封板** | **¥110,552.72** | **+10.552720%** | **13.6784%** | **510** |

两种值得注意的结果：

- **同日模式下封板判断完全没影响**，四组数字与加规则前逐笔一致。这是合理的：同日模型在信号当天就成交，那时还不存在“持有并要卖出却卖不掉”的情形。
- **次日模式只影响关闭过滤器组**：成交 1122→1102（少了 20 笔卖出），收益 −28.20%→−29.29%，回撤 36.25%→36.44%。开启组一笔都没变，说明该组在封板日没有恰好要卖出的持仓。
- 方向符合预期：被拦下的是跌停封板日的卖出，持仓被迫继续承担下跌，因此收益和回撤都略微变差，而不是变好。

四组回放与独立核算均退出 0，差异 0、不可交易成交 0，研究输入库 SHA256 前后不变。精确值与指纹见 [对照摘要](assets/seal-comparison-2026-11-12.json)。

**结论：封板规则让“关闭过滤器”这一组的可执行口径更差一点（−29.29%），也让“开启组 +10.55%”这个目前唯一为正的结果第一次通过了可成交性检验**——它在该组没有改变任何一笔成交，但不代表它已经稳健，只说明这组没有踩到封板日的卖出。所有数字仍是同日/次日收盘模型，不是样本外，也不是可执行总回报。
