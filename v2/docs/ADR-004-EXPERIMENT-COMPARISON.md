# ADR 004：V2 独立策略实验比较（只读口径）

状态：提议（Draft）。本轮只提交 ADR，不实现比较服务；实现必须是独立 PR，并与 V1 退役变更分开。

## 问题

ADR 001 已让每个实验拥有独立资金与账本，ADR 002 固定了离线市场数据包，ADR 003 让"同一策略 + 同一研究输入"可以重做核验。下一步需要回答：**两个独立实验放在一起看时，哪些数字可以比较、哪些绝对不能编造。**

风险很具体：把"现金变化"当成"净值收益"，或在没有持仓估值价格时计算收益率、夏普比率与最大回撤，会产出看起来专业但完全不成立的结论。

## 决定

### 1. 比较的前置条件（不满足即拒绝）

两个实验必须同时满足：

1. 同一研究输入：`research_input_digest` 相同（ADR 003 的内容身份）；
2. 同一市场数据包：`market_data_pack_id` 相同（ADR 002）；
3. 同一执行策略版本与同一费用模型（`execution_policy_version`、佣金/印花税/最低佣金）；
4. 同一初始资金 `initial_cash_cents`（否则数量口径不可比）；
5. 同一日期范围与 as-of 规则；比较窗口取两者的交集，窗口外用"不可比"标注而不是裁剪掉；
6. 两个实验都必须通过 `verify_replay`；固定策略的实验还必须通过 `verify_research_reproduction`。任一失败 → 整个比较失败，不输出部分结果。

允许不同的只有**策略工件本身**（`strategy_version_id` 与内容摘要）——那正是比较轴。研究输入不同、数据包不同、策略参数不同却复用同一 `strategy_version_id` 的情况已分别由 ADR 002/003 拒绝，比较不重复接受。

### 2. 可比口径

比较是**按决策时点对齐的事实并置**，不是重新撮合、不是重新分配资金。

| 事实 | 口径 |
| --- | --- |
| 决策 | 以 `decision_at` 为槽位；两个实验在同一时点都有决策才算"同时点对"；只有一方有 → 计入 `unmatched_decisions`，不插值、不补造 |
| 拒绝 | 按稳定 `reason` 代码分组计数；不同拒绝原因不合并成"失败" |
| 成交 | 数量、价格（整数分）、方向、交易日逐字段并列；不做加权平均掩盖差异 |
| 费用 | 每笔成交的绝对费用（整数分）与合计；不年化、不折现、不换算成"费率优势" |
| 现金 | 只报 `cash_cents` 绝对值与由成交引起的差额；不称为收益 |
| 持仓 | 只报数量与买入日（T+1 可卖数量）；不报市值 |
| 身份 | 比较结果绑定两个 `experiment_id`（含内容摘要）与上述前置条件的摘要 |

同一时点数量不同（例如预算导致 700 vs 400 股）时，只并列陈述，不归一化成"单位收益"。

### 3. 估值禁令（硬约束）

当被持有证券在比较 as-of 时点**没有**审核过的可估值价格（数据包只提供观察点，不提供连续盯市）时：

- **不得**计算净值（NAV）、累计/年化收益率、夏普比率、索提诺比率、最大回撤、波动率、胜率、盈亏比或任何由市值推导的指标；
- 比较结果必须显式输出 `valuation: "unavailable"` 与缺失原因（缺哪个时点、哪个证券、哪个数据包），并仍然允许输出第 2 节的现金/成交/持仓事实；
- 只有在数据包**明确声明**了比较时点的可估值价格集合时，才允许计算上述指标，且必须把价格来源与版本写进比较摘要；
- 合成样例（`offline-fixture`）产生的价格不得用于宣称收益或策略优劣，只能在文档中标注为"合成回归输入"。

### 4. 只读

- 比较只读取独立实验的只读投影（`state` / `runs` / replay / research-reproduction），**不写入**任何资金、成交、持仓或实验状态，也不创建新实验；
- 比较结果是由两个实验身份与口径版本派生出的**只读模型**，可以带内容摘要，但不是账本事实，不做持久化权威；
- 任何"以比较结果修正某个实验"的需求，都必须走新实验重新执行，不允许回写。

### 5. 明确不做

- 不做 V1 的策略评分、评分排行榜、自动晋级、进化调度、候选搜索或共享资金池；
- 不做跨数据包或跨研究输入的"近似比较"；
- 不做统计显著性声称：样本量、多重检验与置信区间属于另一个决策，本轮只固定"事实如何并列"；
- 不引入新服务、消息队列、ORM 或插件框架；比较应是既有只读投影的一个消费者。

## 验收（下一轮实现时的最小集合）

1. 前置条件不满足（输入/数据包/策略版本/初始资金/窗口不一致，或任一实验 replay/重做失败）→ 明确拒绝，不输出部分结果。
2. 同一时点对、单边决策、拒绝原因、成交字段、费用合计、现金与持仓数量逐字段并列；单边决策不被重复计算。
3. 没有估值价格时，任何净值/收益率/夏普/回撤字段缺失且状态为 `valuation_unavailable`；有价格时才允许计算，并把价格来源与版本写入摘要。
4. 比较不产生任何写入：对两个实验的 `state`、`runs`、成交与完成状态在比较前后逐字段相等。
5. 服务重启（新进程、同一 SQLite 文件）后同一比较仍产生相同结果与相同摘要。

## 未决问题

- 比较窗口是"两个实验日期范围交集"还是"由调用方显式指定"？倾向显式指定并拒绝越界。
- 是否需要把比较摘要持久化为只读记录（当前倾向：不持久化，按需重算）。
- 可估值价格集合由数据包清单扩展还是由独立的价格证据引入（涉及 ADR 002 的清单版本）。
