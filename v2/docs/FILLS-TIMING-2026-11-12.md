# 成交时点：同日收盘 vs 下一交易日（2026-11-12）

分支 `codex/v2-store-boundaries`，改动基于已推送的 `1e7c3e7` 之后的时序改造。只改成交时点，不改评分公式、市场过滤阈值、手续费、整手、T+1、止损参数、单票额度或资金分配。两组使用完全相同的 813 份逐日输入窗口（日期、覆盖、股票数、价格集合 digest 逐项相同），研究输入库 SHA256 前后不变。

## 两种口径

| 口径 | 决策依据 | 成交价 | 止损触发 |
| --- | --- | --- | --- |
| `same-close`（原来的模型） | 当日收盘 | 当日收盘 | 当日收盘 |
| `next-session` | **前一交易日收盘** | 当日收盘 | **前一交易日收盘** |

`next-session` 下，产生订单那一刻不可能看到成交价；止损也按“已有证据”判断，当天跳空高开不会撤销前一天已经触发的止损。停牌仍按当日不可成交处理，不会用陈旧价格成交。订单不模拟盘中执行：跳空穿过止损位时，按收盘价成交，不按跳空价。

运行：

```bash
cargo run --release --locked --manifest-path v2/Cargo.toml --example regime_ab -- \
  --db work/real-history/db/research-market-halt-boundary.sqlite3 \
  --from 2023-07-05 --through 2026-11-11 --initial-cash-cents 10000000 \
  --fills next-session > work/ab-next.json 2> work/ab-next.log
python -B v2/research/verify_ab.py work/ab-next.json \
  --db work/real-history/db/research-market-halt-boundary.sqlite3 \
  --out work/ab-next.verification.json
```

`--fills` 省略时默认 `same-close`，与之前的行为逐笔一致：本轮修复后用它重跑，期末、收益、回撤、成交数都精确复现已发布结果，作为“默认路径未被改动”的对照。

## 结果（本金 ¥100,000，813 个结算日）

| 版本 | 期末资产 | 精确收益 | 最大回撤 | 成交 | 手续费 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 关闭过滤器 / 同日 | ¥79,018.73 | −20.981270% | 32.0198% | 1122 | ¥9,214.27 |
| 关闭过滤器 / 次日 | ¥71,798.15 | −28.201850% | 36.2512% | 1122 | ¥9,793.85 |
| 开启过滤器 / 同日 | ¥119,318.05 | +19.318050% | 13.6873% | 496 | ¥5,960.95 |
| 开启过滤器 / 次日 | ¥110,552.72 | +10.552720% | 13.6784% | 510 | ¥5,807.28 |

次日后两组收益都下降：开启组少赚约 8.77 个百分点，关闭组多亏约 7.22 个百分点。**开启组的回撤几乎不变**（13.6873% → 13.6784%），关闭组回撤反而扩大（32.0198% → 36.2512%）。也就是说，同日模型的高估集中在收益一侧，而不是“回撤被低估”这么简单。

四组回放与独立核算均退出 0，账本/收益/显示精度差异 0，停牌与不可交易成交 0。精确数值、年度片段、日均现金占比和指纹见 [对照摘要](assets/fills-timing-comparison-2026-11-12.json)。

## 结论

- 同日收盘模型确实含有可观的前视便利：用产生信号的那根收盘价成交，等于免费获得一根 K 线的信息。改成次日成交后收益明显回落，这是更接近可执行的起点，也是后续所有对照应采用的口径。
- 过滤器在两种时点下的相对作用方向一致（次日组仍比关闭组好约 38.75 个百分点），但绝对收益从“接近盈亏平衡”变成“仍需改进”。
- 这仍然不是可执行总回报：**涨跌停封板未建模**。实测全期触及涨停的行占 0.879%、跌停占 0.282%，其中 806 行是全天同一价位的跌停——那种日子想卖也卖不掉。当前对“该卖没卖掉”和“涨停买不进”都过于乐观。
- 没有公司行为现金/股数权益：分红送转不进入账本，除权跳空会被当成真实亏损或涨幅。

## 下一步顺序

1. 涨跌停与停牌可成交性：用当日开高低与板块涨跌幅上限判断封板，禁止在封板方向成交（已有 806 行单边跌停样本可作验收）。
2. 公司行为：分红、送转、拆并股的现金与股数调整，带明确的公告可见时间。
3. 冻结参数做分期与样本外，并把仓位暴露调到相近水平再比较，区分排序、仓位、过滤器、时点各自的贡献。
4. 之后再进入因子表达式、影子策略与晋升。
