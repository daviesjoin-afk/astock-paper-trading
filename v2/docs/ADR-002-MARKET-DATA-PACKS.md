# ADR 002：固定离线市场数据包

状态：接受。基线为 #354 合并后的 dab99b59422b72dbd0e4f8f85f40a5559cb8c74d，完整 11 项检查成功。

现状：实验只接受一个 pack ID；证据主键只有 source/quote_id；open 与 replay 将全库唯一快照和当前编译快照比较。新上下文会占用旧上下文的位置，旧实验无法独立引用旧输入。

决定：复用 contract/calendar/instrument/Store/query，不增加服务、依赖或空模块。Store 独占受审核清单的登记与证据写入；Domain 只处理显式传入的固定快照。只支持明确列出的两个 offline_fixture 包，不提供上传/任意登记 HTTP 接口。未知包拒绝。

每个 MarketDataPack 清单固定 pack_id、数据版本、offline_fixture 等级、覆盖日期、来源、内容摘要和完整日历/时段/证券快照。包 1 保留原始内容；包 2 是相同来源资料下人为缩窄到 2026-10-30 至 2026-11-05 的测试集合，并非新的市场认证。包 2 的证券证据版本独立，不改变执行算法。

清单描述不可变的市场上下文和证据命名空间；证据通过既有不可信离线导入逐条追加，同一包内同身份异内容冲突。内容摘要覆盖固定快照，不声称包含未来追加证据。实验的完整输入由固定清单及每次决策记录的完整证据（含缺失）组成。合成价格/容量不是供应商行情。

数据库一次升级为 schema 7：以 pack_id 保存清单/快照，证据主键增加 pack_id；实验和决策固定包清单引用，防止引用被替换。旧 schema 6 在写入前明确拒绝，不自动迁移。schema 7 内增加已审核包是数据登记，不再改变交易表。执行策略版本保持 6，不能用 schema 或包版本代替规则版本。

启动与回放按记录的 pack_id 校验该包完整内容，不与 latest 比较。新增包必须保留旧包的审核定义；缺失/未知/被修改的旧包明确失败，不用其他包回退。已完成实验不追加决策，后续 B 证据不能改变 A。

验收先提交四条真实失败行为：选择第二包、同名外部报价异价、旧完成实验重开、不同覆盖范围独立选择。第三条基线测试用替换唯一存储上下文来模拟旧设计安装 B 的必经耦合，不把数据库篡改当成可信输入；修复后改为 Store 登记经过审核的 B 并保留 A，另行负向测试实际篡改必须拒绝。

执行入口仍是旧有离线导入命令，但 QuoteImport 升为 2，QuoteEvidence 升为 5，ExecutionLiquidity 升为 2，SimulationRequest 升为 4；嵌套 QuoteRef 必须包含包 ID 并保持一致。实验契约形状不变，Store 在创建时内部记录完整清单引用，普通调用者不能提交或修改该引用。已有实验的重复创建也不能修复/替换缺失数据包。

清单摘要为三个源快照文件的 SHA256；Python 标准库测试在 CI 核对实际仓库字节。Rust 不新加摘要库，通过将整个已保存清单/快照与相应审核定义逐字段比较检测篡改，包括摘要、来源、覆盖、身份及版本。同 ID 的替换登记在事务内失败。这里的信任根是保留旧定义的受审核程序构建，不是自签名数据包或外部供应商认证。

schema 6 文件必须继续由原始程序读取，本轮没有迁移。schema 7 中只要原包定义、规则版本和记录完整保留，已完成实验即可跨新包登记及进程重启回放。包 2 损坏时运行中的 A 查询仍可工作；启动发现任意已登记包或实验引用损坏会拒绝整个文件，避免带着已知损坏继续写入。
