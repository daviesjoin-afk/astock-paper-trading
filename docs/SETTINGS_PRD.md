# 设置中心 PRD（settings-v1）

## 1. 目标

在不改变五套策略身份、成交账本和历史归档的前提下，提供一个可审计的设置中心。用户可以调整共享资金、周期、策略参与范围、仓位风控、AI 接口和自进化频率；后端负责范围校验、动态计算和安全边界兜底。

## 2. 信息架构

新增一级菜单“设置中心”，下设四个二级菜单：

1. **模拟盘与资金**：默认启动金额、模拟周期、下一周期启用策略。
2. **仓位与风控**：共享池席位、共享敞口、单票金额、动态最小建仓利用率。
3. **策略参数**：五套策略的风格、最大席位、单票权重和策略敞口。
4. **AI 与自进化**：AI 供应商、审阅/调参开关、调参模式、API Key 掩码状态、自进化周期。

一级菜单、二级菜单和当前值都支持刷新后恢复；地址栏使用 `#settings/<section>`，便于直接打开指定分组。

## 4. 动态行为与计算

### 4.1 动态最小建仓金额

每次下单前重新读取最新风控设置，计算：

`floor_to_100(周期资金 × 共享敞口上限 ÷ 有效席位上限 × 席位利用率)`

席位利用率默认 60%，因此保留约 40% 的共享空间给风险控制、费用、价格变化和后续加仓。该金额不是固定 10,000 元；例如 100,000 元周期、15 席、82% 敞口、60% 利用率时为约 ¥3,200。

### 4.2 单票最大金额

单票有效上限为：

`min(策略净值 × 策略单票权重, 配置的绝对金额上限)`

绝对金额为 0 时只使用策略权重。该上限只影响下单数量，不绕过止损风险预算、现金、共享池敞口、行业集中度、T+1 和涨跌停校验。

### 4.3 周期与策略集合

保存“模拟盘与资金”或“策略参数”后，设置写入运行库并留下审计，但当前周期不被改写。创建/启动新周期时读取最新设置，按启用策略重新分配共享资金并写入周期的 `enabled_strategies` 与 `duration_days`。旧周期和归档快照保持不可变。

### 4.4 风控设置即时生效

席位上限、共享敞口、单票金额和最小建仓利用率在下一次扫描/下单前读取。席位分配版本指纹包含这些输入，修改后会生成新的分配版本；收缩只限制新开仓，已有持仓通过原有分阶段退出流程处理。

### 4.5 自进化周期

后台 `adaptive_runner --session close --trigger scheduled-*` 在执行前检查最近一次已完成学习时间。距离小于设置的小时数时记录 `skipped_due_interval` 并正常退出；人工触发不受该间隔阻断。该设置只控制学习频率，不会放开 AI 自动应用或改变交易硬规则。

## 5. 安全与审计

- 设置值只允许白名单键；数值范围由后端再次校验，前端限制不作为安全边界。
- 至少保留一套策略，启用集合只能来自五个固定策略 ID。
- API Key 不进入统一 GET 响应明文、HTML、日志或 Git；页面只显示 `configured` 和掩码预览。写入接口使用 JSON body，避免把凭据放入 URL。
- AI 自动应用恒为 false；AI 只能产生审阅或有界候选，仍需质量、跨源和人工确认门禁。
- 每次有效变更写入 `paper_runtime_settings_audit`，记录键、旧值、新值、操作者和时间；同时写入 `paper_audit` 的 `settings_changed` 事件。
- 运行库和历史数据不进入开源仓库；推送前继续执行地址、凭据、Key、私有配置和运行数据脱敏扫描。

## 6. API 合同

- `GET /api/settings/`：返回分组设置、默认值、元数据、当前/下一周期、生效预览、掩码 AI 状态和最近审计。
- `POST /api/settings/?confirmed=true`：JSON body 可含 `simulation`、`risk`、`strategy`、`evolution`、`ai` 分组；仅返回脱敏快照。
- `POST /api/settings/ai-key?confirmed=true`：JSON body 含 provider、可选 api_key/base_url/model/enabled；响应不回显明文 Key。
- `GET /api/settings/audit`：分页上限 200 的最近设置审计。

## 7. 验收标准

1. 新克隆启动后无需手工建表即可打开设置中心，默认显示五套策略、¥300,000、长期、15 席、82% 和 24 小时。
2. 修改周期、资金或策略集合后，当前周期展示保持不变；新建周期采用新值并能在周期快照中复核。
3. 修改共享敞口/席位/单票金额后，下一次预检和自动下单的 sizing 审计字段显示新边界；动态最小建仓金额随输入变化。
4. 设置中心在移动宽度下四个二级菜单可横向访问，表单有可见标签、焦点状态、错误提示和至少 44px 操作目标。
5. API Key 写入后只能看到掩码；仓库扫描不得发现真实地址、凭据、Key、数据库或历史运行记录。
6. 单元测试覆盖默认值、更新原子性、未知键、非法周期、空策略集合、审计记录、动态金额和单票金额上限；现有纸面交易、Docker smoke 和前端镜像校验继续通过。
