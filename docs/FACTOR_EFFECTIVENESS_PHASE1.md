# 因子有效性评估：第一阶段

第一阶段回答“已保存候选中，因子排名与后续价格收益有什么关系”，产出只读报告并供现有 AI 调参审核读取。它不调整参数，也不估算改权重后的账户净值。

## 使用方法

在仓库根目录运行：

```bash
python backend/factor_effectiveness_report.py --asof 2026-10-21T19:00:00+08:00
```

默认读取数据目录中的 `paper_trading.sqlite3` 与 `klines/`，生成报告目录中的 `factor_effectiveness_report.md` 和 `factor_effectiveness_report.json`。可通过 `ASTOCK_DATA_DIR` / `ASTOCK_REPORT_DIR` 隔离数据和产物，或指定：

```bash
python backend/factor_effectiveness_report.py --paper-db /path/to/snapshot.sqlite3 --kline-dir /path/to/klines --window-days 90 --output-dir /path/to/reports
```

省略 `--asof` 时使用当前上海时间；仅传日期表示该日结束时。报告函数本身无网络调用、不写库、不迁移表；只有命令行导出会写报告目录。源库缺失时返回不可用状态，不会创建空数据库。

## 口径与范围

- 同时读取活跃和归档信号，包含未成交、被拦截的候选，避免只观察赢家。它仍然是筛选后的条件样本，不能外推到全市场或筛选前的候选。
- 优先读取冻结决策快照中的时间、因子和评分配置；历史记录缺少这些字段时，读取当时保存的信号时间与候选因子。不会使用今天的因子重建历史。已被刷新覆盖的更早快照不可还原。
- 按账户、策略 ID、策略版本、校验值、因子计算版本、评分输入版本（如有）、权重配置分组。字段不齐全的分组保留覆盖统计，但不计算 IC 或分组收益。
- 同一信号的归档副本只计一次；副本因子或身份冲突时排除。每日每个分组内同一股票只计一次；多个保存值冲突时排除，并报告数量。
- 前瞻收益完全复用 `selection_labels`：决策日后首个交易日收盘作为起点，再取其后第 1/5/10 个交易日收盘。使用实际决策时间，不能因为 `signal_date` 写着昨日就回填昨日收盘。
- 交易日取本地 `BENCH_000300.csv` 的日期，依赖缓存完整性；缺少该序列不退回个股日期或工作日推算。缺少价格、日历或收益窗口未到期时分别保留状态，不填零。
- 收益为原始价格收益，不扣费用、不认证可成交性或复权，也不单独认证财务披露时点；不代表成交收益、账户盈亏或因果贡献。

## 输出如何解读

Rank IC 是因子排名与后续收益排名的相关程度。每个日期先在同组股票内计算，再对日期等权平均，不把不同日期的股票混在一起计算一个相关系数。

每个因子、每个收益窗口输出：覆盖率、缺失与无效因子行数、有效配对数和日期数、平均 Rank IC、正 IC 日期比例，以及高低分组的平均收益与差值。高低分组按约三分位划分；边界相同则不计算组间差，不随意拆开同值样本。不同日期、不同配置不合并。

单日需至少 5 对有效因子与收益，因子和收益均需有变化。有效 IC 日期不足 20 时标记 `insufficient_dates`；身份字段不完整为 `incomplete_identity`。20 日仅是描述性展示门槛，不是显著性检验，尤其不能把重叠的 5/10 日窗口当作独立观察。

完整 JSON 包含逐日统计、信号表与行 ID、保存内容摘要、决策时间、实际使用的因子、收益标签以及价格文件摘要，可供复算。Markdown 供人工阅读。

## AI 接入

现有 `deepseek_advisor.collect_evidence` 增加 `factor_effectiveness`，提供每个账户最新观测时刻的配置分组；并列配置均保留，更早分组数量明确列出，完整历史通过命令行报告查看。最新观测配置不一定等于当前账户配置，摘要保留权重供核对。

`ai_review_service` 提示词明确：样本不足、身份不全或数据不可用不能作为调参依据；Rank IC 不能转成“权重移动多少、净值改善多少”的承诺。`deterministic_findings=[]` 仅表示已执行检查未发现异常，不表示缺少信号，也不表示因子有效性证据充分。现有共识和应用门禁保持原行为。

## tq_breakout 实时情绪输入

tq_breakout 使用包含情绪因子的模型、且未采用板块风格时，在有当日实时行情的候选扫描中读取现有东方财富人气榜前 100 名。实时决策日与上一交易日技术因子截止日分别处理；历史日期或没有实时行情的回放不读取今天的人气榜。榜外股票、空返回或读取失败继续保持情绪缺失，按原有规则重新分配可用因子的评分权重。

标准化沿用现有规则：当轮有效人气样本少于 5 个或观测值全部相同时，已观测样本记为 0 分，未观测股票仍为缺失。

这次输入修订标记为 `factor_input_version=paper-tq-sentiment-v1`，保存于候选的 `score_components`，并随原有流程冻结到决策快照。归因按此字段分组，避免把缺失输入时期与接入后的时期混合；旧样本保持原分组 ID。该标记独立于注册表中绑定交易周期的不可变策略版本，不改写周期绑定和历史记录。其他账户、模型权重、交易与风控规则保持原值。

## 本次基线与验证范围

开发基线为实际服务器源码与 API 容器均核验的 `d1eacf2`；从该版本开展第一阶段。下列记录对应本地开发验收，服务器发布结果另行记录。

2026-10-21 的隔离快照验证中，去重与冲突排除后共 4,213 条候选、36 个决策日期，2,649 条保留可用因子。按当前版本及权重拆分后，有效日期不足 20，报告明确保留证据不足状态。该记录只描述此次快照，运行新报告会按实际数据重新计算。
