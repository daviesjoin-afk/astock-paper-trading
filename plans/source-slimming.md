# 源码瘦身与大文件拆分

## 目标和验收

遍历受版本管理的源码、测试、入口和部署配置，删除有明确废弃依据的实现及一次性开发脚本；准备按职责拆分大文件。不得改变 API、交易规则、事实来源、数据库迁移和部署入口。完成后检查后端全套测试、前端单元测试、ruff、语法和差异格式，并做反向核查。

## 范围地图

- `backend/`：生产模块、单元测试及架构检查。
- `frontend/src/`、`frontend/styles/`、`frontend/tests/`、`frontend/e2e/`：入口、浏览器绑定、构建和测试。
- `deploy/`、`.github/`、根目录启动/容器配置：独立调用的入口。
- `work/`：历史修补、复现、故障注入与运维工具，逐类判断用途。

## 阶段

- [x] M1：静态遍历 900 个受版本管理文件，解析 676 个 Python 文件；核对入口、无调用定义、重复测试和大文件。
- [x] M2：清理无调用实现、过时测试及一次性修补材料，保留可重复运行的故障注入与运维入口。
- [x] M3：完成检查、对抗性复核、更新精简清单和后续拆分验收标准。

## 决策

- 2026-10-22：保留正式研究契约/服务/仓储分层；无直接生产导入并不等于废弃，独立入口、动态依赖和受控研究能力均需单独核对。
- 2026-10-22：保留历史审计 JSON 证据及有效故障注入脚本；只清理明确的一次性源码修补和 PR 发布材料。
- 2026-10-22：本轮不做交易编排的大规模搬迁。先删死代码并给出按既有模块承接的拆分次序，避免新增万能依赖对象或通用框架。

## 验证记录

- 基线 6,031 项：19 个 Windows GBK 输出错误，9 跳过；19 项切换 UTF-8 原码重跑全部通过。
- 前端 183 项通过；构建产物与提交内容一致；后端 ruff、compileall、差异格式检查通过。
- 保留生产 AST 等值、导入完整性、Provider 写入反例、正式采样上限反例检查通过。
- 清理后全量 6,029 项：6,019 通过、1 项旧架构断言失败、9 跳过。同步旧断言后，周期服务整个模块 12 项全部复跑通过；没有再改生产实现，未重复运行全套。
- 43 个文件删除、15 个无调用函数删除、2 项重复测试合并；生产 Python 减少 497 行、work Python 减少 1,565 行，另删 26 份历史 PR 草稿。完整结论和按职责拆分顺序见 `docs/SOURCE_SLIMMING.md`。
- 完整输出保存在忽略的 `.codex/` 目录；本轮没有未解决的测试失败。
