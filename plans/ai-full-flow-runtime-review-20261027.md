## 4. 全流程仍未闭环：三个明确缺口

### P1：生产事件缺选股因子表，回放确定失败

`paper_trading.py` 收盘投递调用 `research_orchestration.session_from_quotes()`，没有传 `factor_table`，于是冻结会话中的该字段为 `None`。研究候选仍能登记，真正的回放调用 `strategies.run_strategy()` 后失败：

```text
AttributeError: 'NoneType' object has no attribute 'index'
```

隔离复现使用生产相同的投递形状、真实候选/worker/回放代码，只在临时数据库运行：1 个会话，0 个发布会话，0 条回执，任务终态 `failed`，候选仍为 `running`。

现有测试手工给事件附上 DataFrame（带列名的选股数据表），所以 193 项相关测试全部通过，仍未覆盖实际收盘调用形状。

修复验收应同时满足：

1. 投递当时实际使用的冻结因子表、证券集合与首板集合，不能在回放时重新抓取或补造数据。
2. 无合格因子输入时明确等待/跳过，不投递必然失败的实验。
3. 从真实收盘入口贯通事件、研究任务、双侧回执和结果反馈；重复运行不重复发布。
4. 证明参数变化确实被选股函数消费；不能用空选股或全现金零收益充当有效实验。

### P1：真实模型首轮输出未通过工具调用合同

用当前 `SYSTEM_PROMPT` 与当前生产首轮用户提示词做了两次独立真实 AI1 调用，均被 `DecisionRejected` 拒绝；第二次明确原因是 `continue_requires_next_tool`。耗时分别约 3.783 / 3.807 秒。

当前提示词说明顶层字段和工具名字，但没有给出 `next_tool={name,arguments}` 的完整形状、各工具参数合同，也没有把任务中的 `research_target` 作为首轮上下文发送。模型能返回 JSON，不等于能调用平台工具。

这些是隔离的首轮探针，没有执行完整的校验反馈/修复循环，所以不能据此断言完整循环永远失败；同样不能宣称真实 S1 已验收。S1 指“一条真实研究任务能从事件走到结果反馈”。

修复验收：提供可机器校验的工具参数说明及当前研究目标；用真实 provider 跑完建候选、等待、回放、读结果、发布/淘汰；额外验证非法输出的反馈修复和故障停止，不只测试预设模型回复。

### P2：股票建议检索先取一条，再检查股票，遮蔽其他有效建议

`ai_advice_service.latest_opinion()` 先按策略和动作取最新一行，之后才比较 `payload.code`。依次保存股票 A、B 的有效意见，再查询 A，返回 `None`，尽管 A 的意见仍有效。

隔离复现已确认该行为。修复时应先匹配股票范围，再选该股票的最新意见，并明确全策略意见与股票意见的优先关系；身份、期限、动作范围仍须校验，不能用检索改动绕过它们。

当前生产固定为 `ADVISORY`（建议模式，只记录解释），该缺陷影响意见关联，不应被描述成已经导致了实盘或模拟盘误交易。

## 7. 后续修复（2026-10-27）

本节记录用户授权修复后的变化，前文保留为修复前的现场证据。

- 调度安装：`sync-cron.sh` 在安装定时任务前创建实际部署目录下的 `.locks`。回归在临时项目中执行脚本并实际取得外层锁，不依赖先启动交易 runner。
- 冻结输入：收盘选股通过独立输出参数保存**当轮策略调用之前**的完整因子表、报价证券集合与真实首板集合；不把 DataFrame 塞进交易结果，不用已选股票名单反推研究范围。缺表、缺完整报价时只跳过研究，规则选股照常继续。队列与候选登记也提前拒绝缺因子输入，避免创建必然失败的实验。
- 时间真实性：按实际冻结时刻记录事件与回放决策时间，历史日期不能伪称当时冻结。15:00 之后才取得的数据不能用于证明当日 15:00 已可成交；还没有下一交易日输入时，这类模拟成交保持未证实，也不能把全现金回放作为交易建议的有效依据。
- 数据状态：新研究快照中缺失的停牌及风险标记保留为未知；可成交性继续由原有门禁根据有效报价、名称及其他事实判断，不因缺少其中一个字段就一律拒绝。其他策略继续投递原有行情事件。
- 基准边界：首版候选仍以默认 `tq_breakout.flow` 为研究基准；若活动账户已经使用模型/权重/条件覆盖，明确返回 `research_requires_default_selection_parameters`，不把其他活动参数冒充默认基准。支持这些覆盖属于后续切片。
- 模型合同：给出 `next_tool={name,arguments}` 的明确例子、各工具的 JSON 参数说明、当前目标/基线/范围/精确身份与当前时间；说明实验未完成应等待、恢复后重读结果。没有放宽输出校验或交易权限；提示词版本升级为 `research-agent-prompt-v2`。
- 股票意见：按时间查找该股票或全策略范围内的最新意见，其他股票不再遮蔽它。命中后仍检查身份和期限；不会因为新意见过期而偷偷回退到旧意见。
- 参数消费：验收额外发现回放只传单个权重字段，而生产选股器要求完整权重表，旧变体会被静默忽略。两侧现已冻结完整权重表；为让目标字段的实际比例与记录一致，其他字段按原比例分配剩余权重，再交给既有选股器进行归一化与相关性检查。选股器明确拒绝覆盖时，回放拒绝发布；没有改生产选股规则。新增测试证明实际基础得分变化且目标比例准确。回放版本升级为 `native-paired-replay-v3`，旧回执不重写。
- 实验反馈：研究任务被实验完成事件唤醒后，自动把已提交的最新实验结果加入模型上下文；若模型再次等待已完成的同一个实验，明确终止该等待。对新的市场/收益标签仍允许等待相应事件。
